# HushJolt

HushJolt optimizes distributed network performance with real-time data processing controlled by a centralized data controller and edge agent.

The key benefits of using HushJolt include:

- HushJolt optimizes distributed network performance
- with real-time data processing controlled
- by a centralized data controller

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/HushJolt.git`
2. `cd HushJolt`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
